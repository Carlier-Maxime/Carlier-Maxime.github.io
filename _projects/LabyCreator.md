name: LabyCreator
description: >
  Premier prototype algorithmique de génération et de résolution de labyrinthes en 2D, développé en Java avec Swing. 
  Réalisé sur une architecture CPU séquentielle, le projet implémente les algorithmes de base de création de chemins et de recherche de parcours avec un rendu visuel coloré en temps réel. 
  Cette application a servi de fondation logique et de point de départ pour l'analyse des limites de performance CPU avant la migration complète du concept vers l'architecture massivement parallèle GPU (CUDA) via le projet CudaMaze.
