name: Puissance4
description: >
  Développement en C d'une adaptation du jeu Puissance 4 intégrant un système d'IA multi-niveaux (Facile/Normal/Difficile), réalisé en binôme. 
  L'architecture logicielle est conçue de manière modulaire afin d'isoler la logique métier (le moteur de jeu) des couches d'affichage,
  permettant une exécution double : soit en mode console via le terminal, soit en mode fenêtré via la bibliothèque graphique SDL2. 
  Le projet met également l'accent sur la robustesse du code à travers l'automatisation des processus de compilation (Makefile) et l'implémentation de tests unitaires avec le framework CUnit.
