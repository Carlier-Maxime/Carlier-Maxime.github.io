name: AvatarCreator
description: >
  Application de génération aléatoire d'avatars 2D développée en C++ avec le framework Qt. 
  Le programme assemble des assets graphiques en fonction de probabilités d'apparition et de chemins d'accès 
  entièrement configurables via un fichier texte externe (settings.txt). Cela permet de modifier l'emplacement 
  des ressources ou d'ajuster le taux d'apparition de certains attributs (comme le background ou le type de personnage) 
  sans avoir à recompiler le code source.
